# 文献检索

## 何时使用

- 用户要按主题、篇名、作者、刊名找中文论文；
- 需要一页题录（标题、作者、刊名、年份、被引、下载、链接）；
- 需要把检索结果交给后续的详情或导出技能。

## 硬约束

1. **只读**：不请求、不调用任何 PDF/CAJ 下载。
2. **遇阻即停**：返回 `status: blocked` 时立即停止，把 `signal` 和 `cooldown_until` 原样告诉用户，禁止重试、禁止换关键词绕开。
3. **量**：`page` 取值 1–3，`limit` 1–50；每次调用只返回一个目标页。两次调用之间不要连续轰炸；日上限 300 次由内核强制。
4. **不猜结果**：只转述工具返回的字段，不补全、不虚构作者或年份。

## 调用

工具：`search`

```json
{"query": "IPMC", "limit": 20, "page": 1}
```

### 关键词检索

`query` 是普通词组时走一站式检索。适合“大致找找”。

### 每页条数与年份

- `limit` 1–50：大于 20 时工具会把结果网格切到 50 条/页。
- 一次调用只返回 `page` 指定的那一页（最多 50 条），不会自动合并多页。
- `year_from` / `year_to` 是**客户端筛选**：只对本次抓到的这一页生效，`total` 仍是站点总数。
  如果筛选后为 0，说明目标年份不在这一页，应换 `page` 或改用更精确的检索式，不要连续翻页扫库。

### 排序

`sort` 取值：

- `relevance`（默认）：相关度；
- `date`：发表时间，降序（最新在前）；
- `citation`：被引频次，降序。

排序会让结果网格多刷新两次（先复位相关度再点目标列），每次调用多 2 个请求，仍计入日配额。

### 专业检索式

`query` 里出现 `字段=` 或 `字段%` 时自动切到专业检索页。可显著降低噪声。

可检索字段：

| 字段 | 含义 | 字段 | 含义 |
|---|---|---|---|
| `SU` | 主题 | `TI` | 篇名 |
| `TKA` | 篇关摘 | `KY` | 关键词 |
| `FT` | 全文 | `AB` | 摘要 |
| `AU` | 作者 | `FI` | 第一作者 |
| `RP` | 通讯作者 | `AF` | 作者单位 |
| `FU` | 基金 | `CO` | 小标题 |
| `RF` | 参考文献 | `CLC` | 分类号 |
| `LY` | 文献来源 | `DOI` | DOI |
| `CF` | 被引频次 | | |

运算符（按知网官方语法）：

- `and` / `*`：与；`or` / `+`：或；`not` / `-`：非
- `%`：作者模糊匹配，如 `AU % '陈'`
- 括号分组：`TI='生态' and (AU % '陈' + '王')`

示例：

```
TI='生态' and KY='生态文明' and (AU % '陈' + '王')
SU='北京' * '奥运' and FT='环境保护'
SU=('经济发展' + '可持续发展') * '转变' - '泡沫'
```

## 返回

```json
{
  "total": 595,
  "page": 1,
  "page_count": 30,
  "records": [
    {
      "title": "…",
      "authors": ["…"],
      "source": "复合材料学报",
      "year": 2026,
      "citations": null,
      "downloads": 22,
      "url": "https://kns.cnki.net/kcms2/article/abstract?v=…"
    }
  ]
}
```

检索结果**不含摘要和 DOI**；需要时把 `url` 交给 `scholar-detail`。

## 异常

- `blocked`：风控或验证页，停止。
- `PolicyError`：参数越界（如 `page` > 3、`limit` > 50、使用了未实现的 `source_types`）。
- `ParseError`：页面结构变化，报告并停止，不要重试同一请求。

## 不要做的

- 不要用循环把同一关键词翻很多页；
- 不要为了“多拿点数据”把 `limit` 拉到 50 再本地截断；
- 不要把 `blocked` 解释成“稍后再试”。

# ADR 0004 · 风控即停，不做自动恢复

- 状态：已接受
- 日期：2026-10-20

## 背景

自动化被识别后，继续重试会显著提高账号与 IP 的风险等级。人工通过一次验证通常即可恢复。

## 决定

检测到以下任一信号，立即终止当前计划：

- URL 命中 `/verify/home`
- 页面出现验证码容器
- HTTP 403
- 被重定向到登录页
- 页面出现"安全验证"文案

处理方式：返回 `blocked` + `action_required: manual_verification`，写入审计，设置 24 小时冷却。冷却期内任何请求直接拒绝，不产生网络动作。解除需用户手动验证后执行 `scholar-search reset --confirm`。

## 后果

- 单次任务可能被中断，这是刻意的取舍。
- 不会出现"越重试越糟"的情况。
- 需要向用户清晰说明恢复步骤。

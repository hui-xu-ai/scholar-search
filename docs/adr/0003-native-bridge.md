# ADR 0003 · 原生消息桥作为默认浏览器适配器

- 状态：已接受
- 日期：2026-10-20

## 背景

CDP 方案会被检测（`navigator.webdriver`、调试端口、自动化特征），且未来检测只会更强。扩展 + 原生消息驱动的是用户真实浏览器，没有调试端口。

## 决定

- 默认适配器为 `bridge`：MCP server ↔ native host ↔ 扩展 ↔ 独立 Edge 实例。
- 扩展只实现九个通用动作，不含任何站点知识；选择器由渠道插件通过计划下发。
- 动作在扩展侧、host 侧、内核侧三处校验。
- CDP 适配器保留接口，默认禁用，仅用于开发与调试。

## 后果

- 站点改版不触碰扩展。
- 安装复杂度上升，由安装器承担。
- 需要维护扩展与 host 的协议版本号。

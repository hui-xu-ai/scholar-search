# ADR 0001 · 微内核与渠道插件

- 状态：已接受
- 日期：2026-10-20

## 背景

知网页面结构会变。若解析逻辑散落在内核、传输层、技能里，一次改版会导致大面积修改。

## 决定

内核只负责：契约、渠道注册、策略、风控、计划编译、审计、缓存。所有站点知识放进 `channels/<name>/<site_version>/`。

渠道通过 `manifest.json` 声明域名、可用动词、最低内核版本；`registry` 选择兼容的最高 `site_version`。

## 后果

- 知网改版 = 新增一个版本目录，内核与工具面不动。
- 旧版本保留，可回滚。
- 新渠道（万方、维普）按同一契约接入。
- 代价：多一层间接，渠道实现需要遵守固定动词表。

# ADR 0006 · 不提供第三方题录入库

- 状态：已接受
- 日期：2026-10-21
- 关联：ADR 0002（只读）

## 背景

用户很自然地想把检索到的题录直接送进 Zotero、EndNote、Mendeley 之类的参考文献库。
技术上也容易：Zotero 7 在本机开了连接器端口，写一个 POST 就能把条目塞进当前库。

## 决定

本项目**不实现**把题录写入任何第三方参考文献库的能力，包括但不限于：

- 调用 Zotero 本地连接器端点或 Web API；
- 改写 `zotero.sqlite`、EndNote `.enl`、Mendeley 库文件；
- 生成"一键入库"脚本、插件、MCP 工具或 agent 技能；
- 在文档里给出可复制的入库代码。

只输出**纯文本** RIS / EndNote 题录。导入动作由用户在对应软件里自己完成。

## 理由

1. **服务条款边界**：本项目的抓取行为已经贴着"个人研究用途"的边界。自动入库把它变成
   "给某个文献管理系统批量供货"，性质不同，风险由项目承担，收益由用户获得，不对等。
2. **责任范围**：一旦写用户的库文件，出问题（条目损坏、重复、附件路径错乱、库被锁）
   就是本项目的 bug。纯文本没有这个面。
3. **凭证与隐私**：接入第三方库意味着可能接触用户的 API key、账号或库内容。
   项目自我约束为"零凭证"，不适合为了便利破例。
4. **可替代性**：RIS 是三十年的事实标准，所有文献管理器都认。少一个自动化步骤，
   换来的是一条清晰的边界，值得。

## 后果

- `export` 工具只返回字符串，不落盘、不推送。
- 文档中的 Zotero 章节只写"如何手动导入"，并明确说明不做自动化。
- 任何 PR 若引入入库能力，按硬约束直接拒绝（见 `AGENTS.md` 第 2 条）。
